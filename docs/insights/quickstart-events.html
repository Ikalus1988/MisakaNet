📊 Quickstart Step Events

How far readers get through the Quickstart on the homepage: which steps' Copy button was pressed, and which "next step" link was clicked. One row per step, one count per day.

Privacy — what is collected: a step id from a fixed list (qs-a1, qs-b3, …) and a per-day count. Not collected: what was copied (the clipboard is never read), query text, IP addresses, user identifiers, or any free text. Aggregates only — there is no way to ask about one visitor. The write path is D1 (counters rows), never Cloudflare KV. See also the privacy policy.

## 1. 判断

### 1.1 先给拒绝理由做直方图，再逐条读

`convert_intake_batch.py` 把 142 条报成一句 **"missing Problem/Root Cause/Fix"**。逐条读是 142 次
判断；按**字段**统计是一次：91 条只缺 cause、26 条缺 cause+fix、9 条缺 problem+cause、
5 条只缺 problem。

再按**标题文本**统计（`^#{2,3}\s+(.+)$` 归一化），31 条里只有 3 种形状：

| 形状 | 条数 | 归属 |
|---|---|---|
| 表单的 `## Problem` 空着，正文写在 `## 现象` | 4（#5513–#5516） | 读者不认识这个词 |
| 同一节写成 `## 根因` | 2（#4748/#4671） | 读者不认识这个词 |
| `## Root Cause（实测修正版）` 这类带括号限定 | 2（#5072/#5234） | 读者不认括号 |

**判据**：一个批次的"拒绝理由"如果是**一句合并的话**，它就不是理由而是噪声。先按字段拆、
再按标题文本拆，一次能修的条数会从 1 变成 8。反过来，逐条读的人永远看不出"这 8 条是同一个词"。

### 1.2 「原因缺失」大多数时候就是答案，不是缺陷

142 条里 **111 条**有 Problem、有 `## Fix (if known)`、有 Verification，**没有 cause**。
那不是读者漏读——是提交者自己没定位到原因。**不要**为了让队列变绿去放宽 cause 的必需性：
放宽的结果是把一句猜测写进 `Root Cause`，而这是整条转换流水线唯一存在的理由。

**判据**：一个 intake 缺某字段时，先问"这个字段能不能从**它自己写的字**里读出来"。
能（标题换了说法、括号加了限定）→ 读者的 bug，改一次读法修一批；不能 → 提交者的活，
留在队列里等他说。

### 1.3 括号限定词必须分类，不能一律接受

`## Root Cause（实测修正版）` 与 `## Root Cause（推测，未证实）` 长得一样，含义相反。
前者可读，后者一旦读出来，猜测就进了"已确立"的槽位。做法：`section(allow_qualifier=True)`
接受括号，但 `_HEDGE_RE` 命中（推测/未证实/suspected/unknown/…）时**整节丢弃**，
intake 带着自己的限定词留在队列里（#4556 今天就是这个状态）。

**判据**：放宽一个匹配规则时，同时写下"我不接受哪一种形状"，并用两个测试各钉一边
（读 / 不读）。只写"接受"的那半个规则，迟早会把 hedge 当成结论。

### 1.4 公共面被拦的 27 条，卡的几乎都是散文

逐条取 `unknown_surface_names` 的返回：27 条里出现的词大多是 `recreated`、`checked-in`、
`task-list`、`scalar`、`appliance` 这类**代码跨度里的普通词**，不是命令名。所以
vol 43 §1.4 那个"计数口径"决定仍然等 owner，这一卷只加了两个真命令（`assoc` cmd 内建、
`loadplatformdescription` Renode monitor）。

**判据**：同一个词被多少条 intake 卡住，比"多少条被卡"更能说明该改哪一边。
一个词卡 1 条 = 那是那条课自己的写法；一类词卡 27 条 = 判据本身错了。

## 5. 坑（本卷实际踩到的）

1. **rebase 之后必须重新生成**：主分支上落了别的课（#5589 一条），`data/lessons.json`、
   `docs/**`、`lessons/index.md`、`ranking-snapshot.json` 全都整文件冲突；reset 到 `origin/main`
   再把新课文件放回去、重跑生成器，比解冲突快得多。
2. **`docs/trust-semantics.md` 要跟着重抄**：它是手抄的生成物，主分支上多一条课，E1 就变一位。
3. **别把 `--check` 的失败接在 `;` 后面**：本卷有一次 `evidence_distribution.py --check` 报
   stale 而 `;` 让后面的 commit 照跑，于是提交了一张旧表——`&&` 或先看退出码。
4. **生成器顺序不变**：`update_lessons_json → build_lesson_pages → sync_lesson_count → export_okf →
   rebuild_lessons_index → export_public_vocabulary → gen_ranking_snapshot`（页面要在 index 之前，
   词汇表要在课程落地之后）。

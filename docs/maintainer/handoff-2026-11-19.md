## 1. 判断

### 1.1 "done but open" 是目前最贵的一类，而且可以机械发现

用集合差一次就量出来：**所有 open issue 的号码** ∩ **所有课 `provenance.issue` 里的号码**。

首测 2026-11-18：`638 open`、`558 条被引用的 intake`、交集 **75**（其中 11 条当时在飞）。处理 64 条后，
`needs-human-review` 从 291 掉到 230 —— 也就是**语料队列里 63% 的"待办"其实早就做完了**。

它们不是某一批的意外，而是流程的稳定产物：转换器写课、合课、**没有关源单**。
后续发现的三条（`#4629` `#4981` `#4793`）都是同一个形状。

**判据**：不要靠读队列判断"还欠什么"，做一次差集。`scripts/intake_receipt.py --sweep` 现在就是这条差集，
并且 `update-lessons.yml` 每天跑一次 `--apply`。

### 1.2 "一个事件没来" 这个形状在本仓出现了四次

同一类缺陷，不同层：

| 位置 | 缺的是哪个事件 | 后果 |
|---|---|---|
| `pr-agent` 时代 | 密钥过期没人发现 | 一条永远红的检查，训练大家忽略红 |
| `approval-watch.yml` | 部署审批没人点 | 记录层僵尸 run |
| `Auto-Merge Lessons` | 检查跑完不是它的触发事件 | 绿的批次 PR 永远等着（`#5350`） |
| `intake-batch-convert` 开的 PR | 检查需要人点 Approve | `action_required`，rollup 里只有 1 条 Cloudflare 构建 |

**判据**：任何"自动"环节都要问一句**谁在什么时候再问它一次**。`wait` 语义本身没错（不该对还在跑的检查发评论），
错的是没人再问。

### 1.3 生成器与平台耦合，而本地绿灯什么都不说明

同一天撞到三件，全部只在本机出现：

- `gen_ranking_snapshot.py` 在 Windows 写 **CRLF**（1476/1476 行），被 LF 门禁抓；
- 同一行钉住的分数 **Windows 0.739701 / Linux 0.739695**，门禁容差 `5e-6`；
- `canonical_lessons` 在 Windows 回退扫盘，把**未跟踪文件**算进语料（1019 vs 1018），
  而那份外来草稿的 `tags:` 是映射列表，`build_lesson_pages.py` 在 `" ".join(tags)` 上直接崩。

已修：`gen_ranking_snapshot.py` 在 `nt` 上拒绝写入（附两个数字与 `--allow-windows` 逃生门）；
`tracked_lesson_files` 三条回退路径都会打一行警告。**其余生成器仍然只能在 POSIX 上跑。**

### 1.4 课门禁有牙，而且两个方向都咬过我

- 我**编出来的**命令名（`deploy_patch`、`md-backup-ok`）→ 应该改写句子；
- **真的标准库**（`ftplib`）→ 应该进 `data/public-vocabulary.json` 的 allowlist，改名会让后来者搜不到；
- 一个普通英文词（`latched`）出现在命令位 → 门禁分不清，改写句子即可。

三种处置不同，判据只有一条：**这个名字对不熟悉该产品的人是否可搜**。

### 1.5 可簇性跟"同一个来源"走，不跟"同一个话题"走

189 条 `needs-answer` 聚类 → **173 个簇**，最大 6、然后 4、3、3，其余全是 1-2。
真簇是"同一次跑动/同一句报错"（如 6 条都是 `Unable to parse MCP response`），不是"45 个人问同一件事"。

**推论**：问题队列的成本是 **1.15:1**，靠"答"不可能收敛；杠杆在提交口（测量已上线）与"按来源成批处理"。

## 5. 坑（本卷实际踩到的）

1. **改一篇课 = 改它的页面 + 改词表**。只改源码不跑生成器，`test_lesson_source_contract.py` 与
   `test_public_vocabulary.py` 各红一次；两个都是正确行为，不是噪声。`lessons/TEMPLATE.md` 也在词表输入里。
2. **`git add` 必须在生成之前**。`canonical_lessons` 只索引 **tracked** 集合，未暂存的课不会进 `lessons.json`，
   而所有计数仍打印 "already consistent" —— 一个安静的假绿。
3. **`git add -A lessons` 会把工作树里的外来草稿带进提交**，它的 `tags:` 若是映射列表会让两个生成器崩。
   本机那次是 `D:\MD\_归档\stray-drafts\` 里的一份 7 月草稿。
4. **中文 slug 的公开页面要等站点发布**，引用前先 `curl -o /dev/null -w '%{http_code}'`；
   英文 slug 通常 301 → 存在。
5. **本机 pytest 有两条环境性假红**：`test_the_gate_can_go_red`（子进程 GBK）、
   `test_a_missing_token_is_an_explicit_error_not_a_pass`（打印中文报错）。在 `origin/main` 上同样失败，别追。
6. **两段 CI 长矩阵会把 job 标成 `cancelled`**，`gh pr checks` 显示为 `fail`。先看
   `gh api .../jobs/<id>` 的 `conclusion`，别误判成真失败。

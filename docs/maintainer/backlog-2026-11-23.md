## `#2113`：到期前 7 天，结论是**不轮换**

- `misakanet`（唯一有真实下载量的包）在 2026-10-06 已完全脱离 token：3.20.0 今天就是用 OIDC +
  trusted publishing 发的，`misakanet-publish.yml` 里已经没有 `NODE_AUTH_TOKEN`；
- 另外两个包（`@misaka-net/misakanet-setup` 0.10.1、`@misaka-net/fatal-guard` 0.3.3）与 manifest
  **同版本**，当前没有待发版本，OIDC 路径从未被真实发布验证过；
- 2026-12-01 之后，这两个包的下次发布会走 OIDC。**如果 npmjs.com 上没配 trusted publisher，它会
  失败，而且失败信息已经写明怎么修**（`misakanet-setup-publish.yml` 的 "Check npm identity" 一段）。

**判据**：为了保住一条从未被走通过的兜底路径去轮换一个 token，换来的是多一个长期密钥要管；
让它在 12-01 过期、下次发布时用真实发布验证 OIDC，失败也只是一次响亮的、可修的失败。

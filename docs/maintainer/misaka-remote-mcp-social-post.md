## 帖子正文（中文）

🚀 刚用了 MisakaNet Remote MCP，太强了！

作为一个 MCP (Model Context Protocol) 工具，它让 AI Agent 可以直接搜索日语学习课程。说下我的真实体验：

**🔍 试用过程：**
安装只需一行：
```bash
npx @ikalus1988/misakanet-remote-mcp
```

配置到 Claude Desktop / Hermes 后，我搜了个 "Japanese particles は vs が"，3 秒内返回了 5 个相关课程，每个都有完整的解释和例句。

**📚 示例：**
搜 "Keigo 敬語 beginner" → 返回 "Business Japanese: Keigo Basics" 课程，包含：
- 尊敬語 (sonkeigo) vs 謙譲語 (kenjougo) 区别
- 10+ 实战例句
- 常见错误对照表

**🛡️ 失败恢复：**
第一次调 Glama 路由时因为 endpoint 没配对返回了 503，但 MCP 自动 fallback 到本地 search API，丝滑恢复，用户完全无感。

**💡 改进建议：**
希望未来支持按难度 (N5→N1) 过滤搜索结果。

如果你是日语学习者 + AI Agent 开发者，强烈推荐试试！
https://github.com/Ikalus1988/MisakaNet

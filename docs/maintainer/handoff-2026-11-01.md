## 3. 可复用的判据

1. **一个门禁要被看见"因为真问题变红"，才配进 required。** Windows 腿 10-31 抓到 CRLF 摘要不一致与 PATH shim 两个 Linux 看不见的问题，都是修因不是消音；它才在 11-01 进 required。
2. **矩阵 job 只有一个判据，几条腿是同一个判据的几个 context。** 所以 `Gate` 有 `also_checks`（一个 gate 覆盖多个 context），而不是复制一份 gate 去"证明"同一条代码路径。
3. **同一件事有两个读者，就会漂。** `--list-gates` 原来自己算了一遍"covered"，和 `missing_hard_gates()` 分家；改成调同一个函数。
4. **摘要要么由生成器写、由测试守，要么会过期。** 而且**换行要归一化**：Windows checkout 的 CRLF 会让字节哈希对不上，那是一次"看起来像被篡改"的假警报。
5. **取不到的校验和等于没有校验和。** 所以 bootstrap 的四个摘要是**内嵌在脚本里**的，不是运行时去下载一个 CHECKSUMS：主站不可达正是镜像存在的原因。
6. **破坏性契约变更先给宽限期，再给一个开关。** `MISAKANET_CLIENT_ID_PROOF=strict` 是 dashboard 变量，执行不需要部署；宽限期内响应带 `deprecated` 而不是 401。
7. **复制一个页面的 token 块，就复制了它的漂移。** 新页面要么从 `docs/_partials/design-tokens.html` 取，要么跑 `sync_design_tokens.py`——这次两者都漏了，`--check` 当场点名。
8. **没量过的数字不要写。** 记录页第一版写了 "516 → 749"，真实是 **658 → 749**；把退化链路的 8.1 s 和干净网络的 111 ms 并排也不诚实。改成一页之后补了 `#4254`。
9. **"最后一次运行是 10-26" 先看调度。** `d1-backup` 是**每周一**，10-26 是周一、成功、下一次 11-02——我上一轮把它判成"可能死了"，是拿日更的尺子量周更。
10. **文件名上的子串过滤会吃掉真文件。** `"TEMPLATE" in name.upper()` 把三篇真课程从证据表、回执解析、心跳面板里一起删了；比较文件名，不要比较子串。
11. **Windows 不能模拟"只有 POSIX 命令的 PATH"**：MSYS 的二进制不可重定位，复制出来也跑不了。这种测试要**按平台跳过并写明原因**，不要用一个假绿糊过去。
12. **接管外部 PR 时：作者与 commit message 留原样，`Signed-off-by` 由接管者补，生成物一律重跑。** `#4049` → `#4257` 就是这条；手改六个生成物正是它 `audit` 红的原因。

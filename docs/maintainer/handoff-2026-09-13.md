## 4. 本轮写下的 lesson

- `lessons/contrib/ci-fork-pr-no-comment-token.md` — fork PR 的红叉为什么没有理由，以及不用写权限的两种发布渠道。
- `lessons/contrib/ci-manual-dispatch-whole-corpus-false-red.md` — fallback 不该**改变门禁的作用域**，该拒跑就拒跑。
- `lessons/contrib/git-checkout-discards-uncommitted-work.md` — **未提交 = 不存在**：
  `git checkout -- .` 用 index 覆盖工作区（已暂存的活下来，未暂存的永久消失）；`reset --hard` 后已暂存内容仍可用
  `git fsck --unreachable` 找回。本轮我自己就是这么丢掉刚验证过的门禁改动的，靠对话记录重建。

## 5. 元教训

- **改完立刻提交**。本轮两次因为"先攒一攒再提交"付出了代价（一次被 checkout 抹掉，一次 git 网络抖动反复重推）。
- **只验一半等于没验**。把测试文件从 ignore 列表里拿出来只是第一步，还得有一次真实 CI run 才能说"它绿"——
  本轮补上了（§2）。同理，门禁收紧后要拿真实的坏输入验（#1656 的 stub）**和**好输入验（已合并课程），两边都做了。
- **红叉必须自解释**。一个不能说明原因的失败，等于教所有人忽略它（本轮修的两处都属这一类）。

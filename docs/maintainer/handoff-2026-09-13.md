## 4. 本轮写下的 lesson

- `lessons/contrib/ci-fork-pr-no-comment-token.md` — fork PR 的红叉为什么没有理由，以及不用写权限的两种发布渠道。
- `lessons/contrib/ci-manual-dispatch-whole-corpus-false-red.md` — fallback 不该**改变门禁的作用域**，该拒跑就拒跑。
- `lessons/contrib/git-checkout-discards-uncommitted-work.md` — **未提交 = 不存在**：
  `git checkout -- .` 用 index 覆盖工作区（已暂存的活下来，未暂存的永久消失）；`reset --hard` 后已暂存内容仍可用
  `git fsck --unreachable` 找回。本轮我自己就是这么丢掉刚验证过的门禁改动的，靠对话记录重建。

## 5. 元教训

- **改完立刻提交**。本轮两次因为"先攒一攒再提交"付出了代价（一次被 checkout 抹掉，一次 git 网络抖动反复重推）。
- **只验一半等于没验**。把测试文件从 ignore 列表里拿出来只是第一步，还得有一次真实 CI run 才能说"它绿"——
  本轮补上了（§2）。同理，门禁收紧后要拿真实的坏输入验（#1656 的 stub）**和**好输入验（已合并课程），两边都做了。
- **红叉必须自解释**。一个不能说明原因的失败，等于教所有人忽略它（本轮修的两处都属这一类）。

# 第三轮（同日更晚）：agent 自启动接入 + 待办重排

## 落地：`integrations/agent-autostart/`（`2af7a41df`、`df24f1d1d`）

目标：让新会话里的 agent **自动**检索失败课程、查不到就提问、到检查点自动脱敏上传 intake。
关键判断是——**光有"规则"不够，必须三件套**：

| # | 目标 | 机制 | 现状 |
|---|---|---|---|
| 1 | agent 能调用 | 注册 MCP `https://misakanet.org/mcp` | Claude Code / Codex 自动写配置；Hermes 一条命令；DSH 无 MCP 客户端 → skill + curl |
| 2 | 知道何时调用 | 规则块注入 `CLAUDE.md` / `AGENTS.md` / `SOUL.md` | 自动（标记块，可 `--uninstall`） |
| 3 | 检查点不靠用户 | **钩子**数轮次：第 20 轮（其后每 10 轮）注入沉淀提醒；失败时注入检索提醒 | Claude Code 自动装 `UserPromptSubmit` + `PostToolUseFailure`；Codex/Hermes 标为手动（未确认的用户级钩子写法不假装做过）|

产物：`install-misakanet-agent.bat`（Windows 一键）· `install_misakanet_agent.py`（三平台，纯标准库）·
`checkpoint_reminder.py`（钩子）· `prompt.md`（可整段粘贴的行为契约）· `README.md`（支持度矩阵 + 安全边界 + 回滚）·
`tests/test_agent_autostart.py`（16 例，全部跑在临时 HOME 上，不碰真实配置）。

**由"真跑"而不是"读代码"发现的三个 bug（均已修 + 加测试）**：

1. 注入块里含**字面 `\n`**（它要展示 intake 调用），而 `re.sub` 会解释转义 → 每次运行都重写文件，幂等静默失效；
2. Codex 的两对标记**前缀重叠**（`misakanet:end` 是 `misakanet-top:end` 的前缀）→ 安装时把自己的顶级块删掉
   （TOML 解析测试抓到）；
3. **`cmd.exe` 里 UTF-8 中文注释会被当命令执行**（.bat 按 OEM 代码页解析），且 Python 在中文 Windows 上
   默认 GBK 输出 → 打印 `✓` 时在**文件已改完之后**崩溃。现在 .bat 全 ASCII、脚本入口强制 UTF-8、两处窗口都在。

## 3. 可复用的判据

1. **`TTFB` 与 `total` 分开量**，才能说清是 worker 还是路径：大 total 小正文 = 路径；TLS 完成后的长 TTFB = worker。
2. **机器上有代理时 `time_connect` 量的是代理**（本例 `127.0.0.1:7890`）。先看 env，再解释 connect。
3. **"三份拷贝一致"要比较模式文本，不只是替换串。** 卡号规则能漂移，正是因为门禁只比了后者。
4. **第二台机器必须和尖峰同时。** 不同时的对照只能说明"那时不慢"。
5. **卡号是形状不是位数**：13–19 连写、4-4-4-4（及 4-4-4-4-1..3）、4-6-5、4-6-4。
6. **词表测试钉住的负例是真门禁。** `assert "mico" not in tokens` 抓到的是投稿课程里的内部平台名与内网域——脱敏不只管凭据，也管内网标识。
7. **生成物冲突的解法是固定顺序**：merge `main` → 冲突文件一律取 `main` 的版本 → 重跑索引/`lessons.json`/页面/排名快照/OKF/证据表/词表 → 提交。手改生成物会过不了"生成器是 no-op"那条测试。
8. **"命中率 15/20" 与 "哪几条差一名" 是两个读数。** 报告只列掉出前三的行时，第二名的行在任何一次运行里都不存在——那正是这 4–5 条一直没人看的原因。
9. **维护者代推外部 PR 时 `git push origin` 推到的是 upstream 同名分支**，不是 author 的 fork；推到 fork 要显式加 remote（本轮踩过一次，同名分支已删）。

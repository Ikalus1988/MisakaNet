## 1. 本轮判断（下次别重新推导）

### 1.2 门禁与站点不一致，两个方向都算 bug

- `tests/test_onboarding_modal.py` 只构造 `docs/<path>.html` 一个候选，于是 `/install/`（由
  `docs/install/index.html` 服务、线上 200）被判成死链。`tests/test_site_pages_are_reachable.py`
  早就同时认"文件 / `X/index.html` / `X.html`"三种形态——**是弹窗门禁比站点窄**。已放宽，并在同一
  提交里加了负向控制（指向 `/no-such-page/` 必须失败且点名 href）。
- 反过来，我一度想教 `resolve_link()` 认"`X/` 由 `X.html` 服务"——那是**死代码**：`os.path.normpath`
  本来就吃掉尾斜杠。门禁里一条永不执行的分支比没有更糟，已撤回。

### 1.3 标签必须说一件可执行的事

`issue-quality-gate.yml` 的规则是"intake 是报告不是规格，不要求 AC"，而
`scripts/intake_triage_classifier.cjs` 只要报告缺四个小节就加 `needs-ac`，之后无人移除。
实测 **24 个开放 intake** 带这个标签（`#4910` 的标签时间线：`intake` 在 14:39:47，`needs-ac` 在
14:39:57，**9 秒后**由同一个函数加上）。删掉那条分支 + 测试驱动真分类器（`#4914`），并清掉 **29 个**
现存标签。

## 5. 坑（都是本轮实际踩到的）

1. **未跟踪的 `.md` 会进生成器**：`export_public_vocabulary.py` 走磁盘。本地重生成前先确认
   `git status --porcelain | grep '^??.*\.md'` 为空，否则你提交的语料里会多一篇 CI 看不到的课。
2. **本地没有 ruff → `test_python_undefined_names.py` 整组 skip**，绿不等于对。要复现 CI，从 PyPI 解包
   wheel 直接跑（`pip download --no-deps ruff` + 解 zip，不需要装）。
3. **沙箱只允许写工作区**：`~/.config` 写入会 `Permission denied`。凭据放 `.cache/`；且**先复制成功再删原件**
   ——本轮我按相反顺序执行，把 GSC refresh token 删了，只能让 owner 重新授权一次。
4. **fork PR 的 workflow run 会卡死在 `queued`**（本轮 `#4702` 卡了三天）：`gh run cancel` 说"已完成"、
   `/approve` 说"不在等审批"、close/reopen 重建后仍卡。解法是维护者把那个 commit **原样 cherry-pick 到
   仓内分支**（保留作者与 `Signed-off-by`）让其进 CI —— 本轮就是这么落地 `#4912` 的。
5. **合并 release PR 后的几分钟内，所有开放 PR 的 `audit` 会变红**（账本/tag 时序），重跑即可，不是代码问题。
6. **Cloudflare 会按 User-Agent 拦**：`Python-urllib/3.11` → 403，`MisakaNet-IndexNow/1.0` → 200。
   任何在 workers 之外的探活都要带 UA，否则"等待就绪"的循环永远等不到，而且**提交本身照样成功**，洞不会自己暴露。
7. **`.html` 在静态资源下不是直出**：`html_handling` 默认 `auto-trailing-slash`，`/x.html` 会 307 到 `/x`。
   所以 GSC 用 meta 标签做交叉验证；IndexNow 提交的也必须是站点真实形态而不是文件路径。

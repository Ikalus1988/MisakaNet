| 数据源（2026-09-30 实测） | 数值 | 读法 |
|---|---|---|
| npm 周下载：`misakanet` / `@misaka-net/misakanet-setup` | 1196 / **116** | 两个数**不可比**：前者每次安装与更新都重新拉，后者一次安装 + npx 缓存 |

## 6. 本轮新增的坑（能省时间）

### 6.1 同一个 bug 修了三次，每次都是"规则窄一格"
站点的 TDZ（`const` 用在声明之前）一天内出现三次：统计卡（页面级）→ 搜索页（入口调用级）→
最后才做对（**跨全部脚本的调用图**，`tests/test_site_script_ordering.py`）。教训：**为刚修完的事故写的门禁，
宽度正好等于那次事故**；修完要问"同类还能在哪出现"。

### 6.2 投影只按"一半的读取方"推导，静默弄坏另一半
`LITE_FIELDS` 当初只看搜索页的打分代码，漏了主页读的 `evidence_level`，于是"证据背书课程数"会算成 0
（应为 26）。现在规则**从页面自身推导**读取集（`tests/test_docs_data_copy.py::test_the_projection_carries_every_field_the_pages_read`）。

### 6.3 别用"替换掉的那个词"检查替换结果
把 `zero-dependency` 换成 `stdlib-only` 时，四个文件留下了 `stdlib-onlyendency`（其中一处在**线上 meta
keywords**，也就是搜索引擎索引到的那行）。原门禁只找**被替换的词**，所以看不见自己留下的残渣 ✗ →
新增规则检查**替换品本身**（`stdlib-only` 必须是完整词）。

### 6.4 无边界正则让门禁的一半空转
质量门禁的验收标准判据是 `|AC|`（无词界）→ `characters`/`exact`/`practical` 都算通过 ✗，只有 checkbox
那半边在干活；同时 `## 验收`（本仓实际写法）**不被识别** ✗。已改 `\bAC\b` + 接受中文标题，并把正则
**从工作流里抽出来直接驱动**测试。

### 6.5 "只报告"形态不会安装（写探针时最容易踩）
`npx @misaka-net/misakanet-setup --report-json --silent` 是**企业/MDM 的只报告形态** ✗ —— 它**不写任何文件**。
写安装冒烟时我先按它断言，差点断言了"根本没发生的安装"。正确顺序是：先真安装，再读报告。
另外：检测读 `$HOME`、写入跟 `--home` ✗ → 隔离要两者都给；机器上没有客户端时"什么都不装"是**正确行为**。

### 6.6 两个包抢同一个 `repository` 会让插件解析装错（#1677 的形状）
`npm search repository:ikalus1988/misakanet` 今天仍返回 **2 个候选**；安全只靠 setup 包**没有 `dsh` 字段、
也没有入口**。所以**不要把 setup 作为第二个 dsh 插件上架**（仓库已有两条门禁明确禁止，且这会复现
`entry file missing: index.js`）。

- "安装器在临时 HOME 里会写配置" ✗：`--only claude` 单独用不写，需先放置客户端的**检测标记**。

## 8. 事故复盘：`--force-with-lease` 覆盖了别人的合并提交（2026-09-30）

**发生了什么**：推送 `feat/one-version-line` 时用 `git push --force-with-lease=<branch>:<sha>`，租约取自我
**刚 fetch 的那个分支**；但本地 `origin/main` 是**过期 ref**（我只 fetch 了那一个分支），于是把远程那个把 main
合进来的合并提交（内含刚合入的 #2515）**覆盖掉了** ✗。

**怎么发现**：推完立刻做祖先检查（`git merge-base --is-ancestor <被覆盖的 sha> HEAD`）→ 不在历史里 ✗。

**怎么修**：`git fetch origin main`（拉**真正**的 main，而不是只拉一个分支）→ `git merge origin/main` →
核验 `805cd793f` 已在 HEAD ✓ → **普通推送**（不再力推）恢复 ✓。

**规则**：力推前不仅要比对租约 sha，还要**看那个 sha 里有什么**；并且**依赖哪些 ref 就 fetch 哪些 ref**，
别假设 `origin/main` 是新的 ✗。手上有别人的分支时，优先 `git merge` 而不是覆盖历史。

## 1. 这一轮定下来的判断

1. **`status: superseded` 永不压过活课。** 稳定分区，不是过滤：只有 superseded 能匹配时仍返回
   （旧错误唯一的记录也好过 `no_match`），否则它排在所有活行之后。838 篇语料、270 条查询实测：
   只有 docker port 那条的 top-3 变了，superseded 进 top-5 的查询 1 → 0，基准 recall@3 不变。（#4520）
2. **BM25 的 `b` 从 0.75 改成 0.5。** 语料文档 72–3,300 token，教科书 0.75 的长度归一化对长正文
   过罚：`ModuleNotFoundError: No module named 'requests'` 里 72-token 的西语 testimonio 靠长度赢过
   带完整 traceback 的德语课。267 条基准 hit@1 **128 → 134**、hit@3 **154 → 158**；德语课与
   `pnpm 11 peer diamond` 都从 rank 2 升到 1。索引里存 `k1/b`，而 docCount/textMode/textVersion
   都看不见参数变化——刷新门禁因此加了 `paramsChanged` 比较，否则新值要空转 20 小时。（#4524）
3. **issue 面不单独开 `format` 口径。** 713 条 `intake` issue **0 条**以 frontmatter 开头，那 20 分
   对每条报料都是常数（≤ 2.0 加权分），不能改变相对排序，只挪动 40 分线；去掉它等价于把线降到 38，
   那是阈值政策而不是刻度修正。37 条样本测量：补偿 4/37 过线、按 80 归一 3/37、去掉整个维度 13/37。
   结论写进了 `score_format` 的注释。（#4518）
4. **Deploy Freshness 要按「部署路径」判断。** 线上 worker 明明就是最后一次 `workers/` 变更，
   但 `main` 每天落多个 `chore(data)` 提交，探针比的是 HEAD → 11-06/07/08 三次计划运行全红。
   现在只问 `live..head` 是否触碰 `deploy-worker.yml` 的三个路径；测不到（浅克隆 / 未知 SHA）仍然
   判 stale——只有「测到空集」才允许变绿。（#4587）
5. **`[Lesson]` 第 4 批 34 篇落地。** 36 条队列：2 条是兄弟投稿的重复（#4509/#4555，正文相似度
   0.94/0.86），1 条需要 domain override（#4511 `node` → `nodejs`）。门禁逼出四处修正，全部记录而
   不是绕过：allowlist 3 个公开名（`comfyui`/`runas`/`set-location`）、3 篇 DSH 课用 `public_analogue:`
   保留内部标识符（错误原文才是可检索的那半边）、1 处引用输出不再当命令 span、lite 投影预算按实测
   480 → 500。**另一个意外**：一篇新课的标题含「零依赖」，撞上已退役口号的措辞门禁（`零依赖` 在
   非 history 文件里被禁），改题改名后通过——这是那道门禁第一次在新课上生效。（#4588）

HTTP MCP Journeys

Crawler/agent-first flows for https://misakanet.org/mcp. This page is intentionally about the remote HTTP Worker path, not local stdio.

Main journey: an agent searches MisakaNet, reads a matching lesson if found, and if no good lesson exists submits a redacted intake. The intake path needs no GitHub account, no email, no browser pairing, and no Bearer token.

remote agent / crawler → HTTP MCP → search → get_lesson OR submit_intake → maintainer-reviewed lesson
HTTP MCP functionAuthUse whenEnd state
misakanet_searchBearer requiredYou have a redacted error, stack trace fragment, tool name, or recovery topic.Ranked candidate lessons.
misakanet_get_lessonBearer requiredSearch returned a promising lesson path/id, or a user referenced one.Lesson markdown for the agent context.
misakanet_submit_intakeNo BearerNo good lesson exists, or a lesson is stale/incorrect.GitHub issue with intake, mcp-intake, pending-review.

Journey 1 — Search misakanet_search

Goal: let an agent find prior fixes before inventing a new recovery plan.

  1. Obtain a read token through pairing or a maintainer-provided token.
  2. Send a concise, redacted query. Do not upload raw logs.
  3. Review top results and decide whether one is actionable.
{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"misakanet_search","arguments":{"query":"GitHub Release large asset download timeout CN","top":3}}}

Success: the agent has candidate lesson paths and scores.

If results are empty or weak, continue to Journey 3 instead of opening a noisy PR.

Journey 2 — Read misakanet_get_lesson

Goal: pull only the lesson the agent intends to use.

  1. Take a path or id from search output.
  2. Fetch the lesson body over HTTP MCP with Bearer auth.
  3. Apply the recovery steps and optionally cite the lesson in the agent's final answer.
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"misakanet_get_lesson","arguments":{"path":"lessons/contrib/github-release-large-asset-download-cn.md"}}}

Success: the agent gets focused markdown, not the whole repository.

This is a read journey; it should not create issues or modify repository state.

Journey 3 — Submit missing lesson misakanet_submit_intake

Goal: make contribution easier than PRs for crawlers and agents.

  1. Search first when possible. If no good match exists, prepare a short redacted summary.
  2. Call tools/call directly. Anonymous clients do not need initialize or tools/list.
  3. Server redacts fields, applies body/rate/spam guards, records a dedup hash, and creates an issue.
  4. Maintainer reviews and converts useful reports into formal lessons.
curl -sS https://misakanet.org/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -H "Origin: https://claude.ai" \
  -H "User-Agent: MisakaNet-Remote-Agent/1.0" \
  -H "MCP-Protocol-Version: 2025-06-18" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"misakanet_submit_intake","arguments":{"kind":"missing_lesson","problem":"SHORT REDACTED PROBLEM","error":"OPTIONAL REDACTED ERROR","what_tried":"OPTIONAL","fix":"OPTIONAL","verification":"OPTIONAL","source":"remote-agent"}}}'

Python snippet (direct tools/call)

import json
import urllib.request

payload = {
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
        "name": "misakanet_submit_intake",
        "arguments": {
            "kind": "missing_lesson",
            "problem": "SHORT REDACTED PROBLEM",
            "error": "OPTIONAL REDACTED ERROR",
            "what_tried": "OPTIONAL WHAT WAS TRIED",
            "fix": "OPTIONAL RECOMMENDED FIX",
            "verification": "OPTIONAL VERIFICATION STEPS",
            "source": "crawler-python",
        },
    },
}

req = urllib.request.Request(
    "https://misakanet.org/mcp",
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Content-Type": "application/json",
        "Accept": "application/json, text/event-stream",
        "Origin": "https://claude.ai",
        "User-Agent": "MisakaNet-Remote-Agent/1.0",
        "MCP-Protocol-Version": "2025-06-18",
    },
    method="POST",
)
with urllib.request.urlopen(req, timeout=15) as resp:
    print(json.loads(resp.read().decode("utf-8")))

Agent/crawler policy

  • Prefer misakanet_submit_intake over PRs for missing, stale, or uncertain lessons.
  • Use PRs only when the agent has repo context, tests, DCO, and a small validated diff.
  • Never submit secrets, raw private logs, internal URLs, customer data, or proprietary files.
  • Keep anonymous intake under 8 KB and low-rate because it creates maintainer-visible GitHub issues.

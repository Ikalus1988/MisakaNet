🪟 Windows Encoding Troubleshooting

Experiencing encoding errors on Windows? You're not alone. This page helps you diagnose and fix common Windows-specific encoding issues with Python, Git, and development tools.

Common Symptoms

  • UnicodeEncodeError: 'gbk' codec can't encode character
  • UnicodeDecodeError: 'charmap' codec can't decode byte
  • Pre-commit hooks failing with encoding errors
  • Git operations showing garbled characters
  • Python scripts failing when writing to console or files
  • PowerShell displaying incorrect characters

Real Failure Examples

Here are actual error patterns Windows developers encounter:

GBK codec error:
UnicodeEncodeError: 'gbk' codec can't encode character '\u2019' in position 42
Pre-commit encoding failure:
[INFO] Initializing environment for https://github.com/pre-commit/pre-commit-hooks.
UnicodeDecodeError: 'charmap' codec can't decode byte 0x9d in position 1234
PowerShell UTF-8 issue:
Exception calling "WriteLine" with "1" argument(s): "The handle is invalid"
Unable to write Unicode characters to console
Python file write error:
UnicodeEncodeError: 'charmap' codec can't encode characters in position 0-5: character maps to <undefined>
Git log encoding:
fatal: cannot convert from UTF-8 to GBK
error: failed to execute prompt script

Root Causes

Windows encoding issues typically stem from:

  • Legacy code page defaults: Windows uses CP1252 or GBK instead of UTF-8 by default
  • Python's locale detection: Python inherits Windows' non-UTF-8 encoding for file I/O and console output
  • PowerShell encoding: PowerShell may default to ASCII or system code page
  • Environment variable gaps: Missing PYTHONUTF8 or PYTHONIOENCODING settings

Quick Fixes

1. Enable Python UTF-8 Mode (Recommended)

PowerShell (current session):

$env:PYTHONUTF8 = "1"

PowerShell (permanent):

[System.Environment]::SetEnvironmentVariable('PYTHONUTF8', '1', 'User')

Command Prompt (current session):

set PYTHONUTF8=1

System-wide (via System Properties):

  1. Open System Properties → Advanced → Environment Variables
  2. Add new User or System variable: PYTHONUTF8 = 1
  3. Restart your terminal/IDE

2. Configure PowerShell Output Encoding

Add to your PowerShell profile ($PROFILE):

$OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::InputEncoding = [System.Text.Encoding]::UTF8

3. Set Git Encoding

git config --global core.quotepath false
git config --global gui.encoding utf-8
git config --global i18n.commit.encoding utf-8
git config --global i18n.logoutputencoding utf-8

4. Python Script-Level Fix

Add at the top of your Python scripts:

import sys
import io

# Force UTF-8 for stdout/stderr
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding='utf-8')

5. Windows System Locale (Advanced)

Enable UTF-8 system-wide (Windows 10 1903+):

  1. Control Panel → Region → Administrative → Change system locale
  2. Check "Beta: Use Unicode UTF-8 for worldwide language support"
  3. Restart your computer

Warning: This may affect legacy applications.

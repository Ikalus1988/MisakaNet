Windows Encoding (GBK/Unicode) Errors

Common on Chinese/Japanese/Korean Windows systems. Fix encoding errors in Python, Git, PowerShell, and CI.

Common Symptoms

  • UnicodeDecodeError: 'gbk' codec can't decode byte 0x94
  • UnicodeDecodeError: 'utf-8' codec can't decode byte
  • UnicodeEncodeError: 'gbk' codec can't encode character when printing non-ASCII output
  • Git commit message garbled or rejected by pre-commit hooks
  • Python script crashes reading files with non-ASCII content
  • pre-commit DCO check fails with encoding error
  • JSON/YAML parsing fails on Windows but works on Linux
  • PowerShell redirects UTF-8 output to a file that comes out mojibake

Root Causes

  • Windows default encoding is GBK (CP936), not UTF-8
  • Python 3.11 and earlier don't default to UTF-8 on Windows
  • Git on Windows uses system locale for commit message encoding
  • pre-commit hooks read files with system default encoding
  • Files created on Linux (UTF-8) opened on Windows (GBK)
  • PowerShell 5.1 uses the system ANSI codepage for > redirection

Quick Fix Checklist

# 1. Set Python UTF-8 mode (fixes most issues)
set PYTHONUTF8=1
# Or permanently:
setx PYTHONUTF8 1

# PowerShell equivalent (session):
$env:PYTHONUTF8 = "1"
# PowerShell permanent (user scope):
[Environment]::SetEnvironmentVariable("PYTHONUTF8", "1", "User")

# 2. Git encoding config
git config --global core.quotepath false
git config --global i18n.commitEncoding utf-8

# 3. For pre-commit hooks, add to .pre-commit-config.yaml:
# default_language_version:
#   python: python3
# And ensure the hook reads UTF-8 explicitly.

# 4. For scripts, always specify encoding:
# open(file, encoding='utf-8')
# subprocess.run(..., encoding='utf-8', errors='replace')

# 5. PowerShell redirection to UTF-8 (5.1):
$PSDefaultParameterValues['Out-File:Encoding'] = 'utf8'
# Or run: chcp 65001

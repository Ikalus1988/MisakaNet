## 6. Upstream Action Fix

During external pilot integration on GitHub Actions runner, the composite action `.github/actions/misaka-intake-bot/action.yml` failed with:
```text
System.ArgumentException: Unexpected type 'MappingToken' encountered while reading 'inputs value'. The type 'StringToken' was expected.
Ikalus1988/MisakaNet/main/.github/actions/misaka-intake-bot/action.yml (Line: 227, Col: 11): A mapping was not expected
```
**Root Cause**: In the `Comment on PR` step, the `env:` block was indented inside the `with:` inputs map (line 226). In GitHub Actions composite workflows, `with:` takes string input parameters; nested mappings within `with:` cause an immediate manifest parsing failure.  
**Fix**: Relocated `env:` to the step level parallel with `uses:` and `with:`.

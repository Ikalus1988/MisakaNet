Summary

FANUC 工业机器人在汽车焊装等场景中需要通过 PROFINET IO 协议与 PLC（如西门子 S7-1200/1500）进行 IO 通信。配置 PROFINET IO 从站需要专用的配置软件，但该软件不是 FANUC 控制器的标准附件，需要单独获取。

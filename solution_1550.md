      - uses: Ikalus1988/MisakaNet/.github/actions/misaka-intake-bot@main

          mode: suggest-and-intake

# MisakaNet Intake Bot External Usage Guide

## Quick Setup (2 minutes)

1. Create `.github/workflows/misaka-intake.yml` with the following content:

```yaml
name: MisakaNet Intake Bot
on:
  workflow_run:
    workflows: ["*"]
    types: [completed]
permissions:
  contents: read
  pull-requests: write
  issues: write
jobs:
  intake:
    if: ${{ github.event.workflow_run.conclusion == 'failure' }}
    runs-on: ubuntu-latest
    steps:
      - uses: Ikalus1988/MisakaNet/.github/actions/misaka-intake-bot@main
        id: intake
        with:
          mode: suggest-and-intake
          source: ${{ github.repository }}
```

2. The bot will automatically:
   - Monitor all workflow failures
   - Suggest relevant lessons when available
   - Create intake issues for new failure patterns

## Advanced Usage

### Suggest-Only Mode
```yaml
with:
  mode: suggest-only
```

### Manual Trigger
```yaml
on:
  workflow_dispatch:
    inputs:
      workflow_id:
        description: 'Workflow ID to analyze'
        required: true
```

## Sample Collection
The bot automatically collects and redacts failure samples. These are used to:
- Improve the decision engine
- Create new lessons
- Identify common failure patterns

All samples are anonymized to protect sensitive information.

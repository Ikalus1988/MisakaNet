# Contributing to MisakaNet

Thank you for your interest in contributing! This document outlines the process.

## Development Setup

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/MisakaNet.git`
3. Create a branch: `git checkout -b feat/your-feature`
4. Install dependencies (see README.md)

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable names
- Add docstrings to all public functions and classes
- Keep functions small and focused

## Testing

- Write tests for all new functionality
- Run `pytest` before submitting
- Ensure CI passes on your PR

## Pull Request Process

1. Update documentation if needed
2. Add an entry to CHANGELOG.md
3. Reference related issues in your PR description
4. Wait for review from maintainers

## Commit Messages

Use conventional commits:
- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation
- `test:` for tests
- `chore:` for maintenance
- `ci:` for CI/CD changes

## Questions?

Open a discussion or issue — we're happy to help!

# MisakaNet

A decentralized AI infrastructure project.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Building

```bash
pnpm build
```

## Project Structure

This is a monorepo using pnpm workspaces. Key directories:

- `packages/web` — Frontend application
- `packages/core` — Core shared logic
- `packages/api` — Backend API services

## Development

The project uses Astro for the frontend, with React components. TypeScript is used throughout.

### Linting

```bash
pnpm lint
```

### Type Checking

```bash
pnpm check
```

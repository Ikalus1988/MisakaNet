# Bài học tiếng Việt - Vietnamese Lessons

## Giới thiệu

Chào mừng bạn đến với bộ bài học Rust bằng tiếng Việt! Đây là tài liệu học tập được thiết kế để giúp người Việt Nam tiếp cận và học Rust một cách dễ dàng.

## Danh sách bài học

### Cấp độ Beginner (Người mới bắt đầu)

1. **[Bài 1: Hello World trong Rust](./lesson-01-hello-world.md)**
   - Chương trình Rust đầu tiên
   - Cấu trúc cơ bản
   - Biên dịch và chạy code

2. **[Bài 2: Biến và Kiểu Dữ Liệu](./lesson-02-variables-and-types.md)**
   - Biến bất biến và khả biến
   - Các kiểu dữ liệu cơ bản
   - Shadowing và constants
   - Tuple và Array

## Cách sử dụng

### Yêu cầu

- Cài đặt Rust: [https://www.rust-lang.org/tools/install](https://www.rust-lang.org/tools/install)
- Editor: VS Code, IntelliJ IDEA, hoặc bất kỳ editor nào bạn thích
- Terminal/Command Prompt

### Hướng dẫn học

1. **Đọc lý thuyết**: Đọc kỹ nội dung bài học
2. **Thực hành code**: Gõ lại các ví dụ, không copy-paste
3. **Làm bài tập**: Hoàn thành tất cả bài tập thực hành
4. **Kiểm tra kiến thức**: Trả lời các câu hỏi cuối bài
5. **Thử thách bản thân**: Tạo các biến thể của bài tập

## Cấu trúc bài học

Mỗi bài học bao gồm:

- 📚 **Giới thiệu**: Tổng quan về chủ đề
- 🎯 **Mục tiêu học tập**: Những gì bạn sẽ học được
- 📖 **Nội dung chính**: Lý thuyết và ví dụ
- 💻 **Bài tập thực hành**: Code exercises
- ⚠️ **Lỗi thường gặp**: Common mistakes và cách tránh
- ✅ **Kiểm tra kiến thức**: Quiz để tự đánh giá
- 📝 **Tổng kết**: Ôn tập những điểm chính

## Đóng góp

Nếu bạn phát hiện lỗi hoặc muốn cải thiện bài học:

1. Tạo issue trên GitHub
2. Gửi pull request với đề xuất của bạn
3. Liên hệ với maintainers

# Введение в программирование

## Что такое программирование?

Программирование — это процесс создания инструкций для компьютера. Эти инструкции, называемые программами или кодом, говорят компьютеру, что именно нужно делать.

## Зачем учиться программировать?

- **Решение задач**: Программирование помогает автоматизировать повторяющиеся задачи
- **Творчество**: Вы можете создавать приложения, игры и веб-сайты
- **Карьерные возможности**: Программисты востребованы во многих отраслях
- **Логическое мышление**: Развивает аналитические способности

## Основные концепции

### 1. Переменные

Переменные — это контейнеры для хранения данных. Представьте их как коробки с ярлыками.

```javascript
let имя = "Анна";
let возраст = 25;
let студент = true;
```

### 2. Типы данных

Основные типы данных:

- **Строки** (String): текст, например `"Привет"`
- **Числа** (Number): целые и дробные числа, например `42` или `3.14`
- **Логические** (Boolean): `true` или `false`
- **Массивы** (Array): список значений, например `[1, 2, 3]`

### 3. Операторы

Операторы выполняют действия над данными:

```javascript
// Арифметические операторы
let сумма = 10 + 5;        // 15
let разность = 10 - 5;     // 5
let произведение = 10 * 5; // 50
let частное = 10 / 5;      // 2

// Операторы сравнения
let равно = (5 === 5);           // true
let больше = (10 > 5);           // true
let меньшеИлиРавно = (5 <= 10);  // true
```

### 4. Условные операторы

Условные операторы позволяют программе принимать решения:

```javascript
let температура = 22;

if (температура > 25) {
    console.log("Жарко!");
} else if (температура > 15) {
    console.log("Комфортно");
} else {
    console.log("Холодно!");
}
```

### 5. Циклы

Циклы позволяют повторять действия:

```javascript
// Цикл for
for (let i = 1; i <= 5; i++) {
    console.log("Итерация " + i);
}

// Цикл while
let счётчик = 0;
while (счётчик < 3) {
    console.log("Счётчик: " + счётчик);
    счётчик++;
}
```

### 6. Функции

Функции — это переиспользуемые блоки кода:

```javascript
function приветствие(имя) {
    return "Привет, " + имя + "!";
}

let сообщение = приветствие("Мария");
console.log(сообщение); // "Привет, Мария!"
```

## Практическое задание

Создайте простую программу, которая:

1. Хранит ваше имя в переменной
2. Хранит ваш возраст в переменной
3. Проверяет, являетесь ли вы совершеннолетним (18+)
4. Выводит соответствующее сообщение

```javascript
let моёИмя = "Иван";
let мойВозраст = 20;

if (мойВозраст >= 18) {
    console.log(моёИмя + ", вы совершеннолетний");
} else {
    console.log(моёИмя + ", вы несовершеннолетний");
}
```

## Следующие шаги

Теперь, когда вы понимаете основы, вы готовы:

- Изучить более сложные структуры данных (объекты, словари)

- Познакомиться с асинхронным программированием
- Начать работу с фреймворками и библиотеками

## Problem

现象 a：选完路线开始导航后，「起/终」标记还赖在地图上。现象 b：多方案预览时路线被上方的速度卡和方案列表挡住，看不到全程，用户以为路线画错了。

## Root Cause

a) syncEndpoints 只在传入坐标时 add，传 nil 时什么都不做，根本没写 remove 分支。b) 取景是自己算中心点 + 缩放，完全不考虑屏幕上有浮层覆盖，几何正确但视觉被挡。

## Fix

a) 传 nil 就 removeAnnotation（把「同步」写成三态：有值→加/更新，nil→删）；
b) 取景用带边距的接口，把被遮挡区域让出来：

```swift
map.showOverlays(ovs, edgePadding: UIEdgeInsets(top: 360, left: 40, bottom: 220, right: 40))
```

边距不要写死成一套，按当前浮层高度算。

## Verification

进导航后地图上只剩路线和车标；多方案预览时三条路线完整可见、不被卡片压住。

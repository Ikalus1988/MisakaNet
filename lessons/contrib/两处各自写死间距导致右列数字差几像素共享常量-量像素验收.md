## Problem

用户截了两张图直接指出「图一数字没有对齐。图二的数字也没对齐。」——并排的两张卡片右侧数值、以及详情页里温度卡与四宫格的数值，左边缘差几像素，肉眼可见地歪。功能没问题，但看起来就是没做完。

## Root Cause

两个独立原因叠加，本质都是「各自写死自己觉得对的间距」，没有共享的列宽/内边距来源：
1. 电池卡右列有一个 `chevron.down` 箭头，速度卡没有 → 右列少 14pt，整体右移；
2. 详情页的温度卡在**卡片级**多套了一层 14pt 内边距（其它卡片没有），数值整体左移。

## Fix

把间距收敛到**一个来源**：

```swift
// 1) 箭头宽度抽成共享常量，两张卡都用它
private static let chevronW: CGFloat = 14

// 电池卡：真箭头
Image(systemName: "chevron.down").frame(width: Self.chevronW)
// 速度卡：同宽透明箭头占位（见 P43，不能用 Color.clear）
Image(systemName: "chevron.down").frame(width: Self.chevronW).opacity(0)

// 2) 温度卡去掉卡片级 padding，改成每个 value 内部对齐
tempValue(...).padding(.leading, 14)   // 与四宫格每格同一个数
```

另外：不要为「好看」给某一张卡单独加图标——其它卡没有图标的，加了必然错位。

## Verification

不要用肉眼验收，**量像素**：预览截图取坐标，数字列 x=999/999、标签列 1044/1046、温度卡与网格列 98/94 与 668/664。残余 2~4px 来自字号度量与内边距取整，肉眼不可辨；**超过 4px 就要重新找原因**。

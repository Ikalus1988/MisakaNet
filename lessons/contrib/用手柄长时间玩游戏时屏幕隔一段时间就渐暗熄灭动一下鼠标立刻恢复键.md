## Problem

用手柄长时间玩游戏时，屏幕隔一段时间就渐暗/熄灭，动一下鼠标立刻恢复；键盘手柄怎么按都无法唤醒屏幕。看起来像显示器省电或面板故障。

## Root Cause

Windows 的"用户活动"只统计鼠标和键盘输入，**XInput 手柄输入不重置闲置计时器**。因此玩手柄时系统认为用户闲置，电源方案里的"关闭显示器"计时到点就执行（本例 AC 300s / DC 180s）。

排除顺序同样重要，先排掉这些再落到闲置计时器：
- OLED 面板自发光衰减 / 内容自适应背光（本例内屏为 IPS，且系统只枚举独立显卡、无核显，故不存在 AMD Vari-Bright 或 Intel DPST）；
- OEM 色彩预设（Armoury Crate GameVisual 等只是 ICC 预设，不按闲置调暗）；
- 第三方护眼/滤镜进程。

## Fix

两条路，按是否接受功耗取舍：
1. 电源方案把"关闭显示器"设为"从不"（`powercfg /change monitor-timeout-ac 0`），最简单，代价是屏幕常亮。
2. 需要保屏保策略时，用 `SetThreadExecutionState(ES_CONTINUOUS | ES_DISPLAY_REQUIRED)` 在游戏期间保持显示，退出时清除标志；同时监听 `GUID_CONSOLE_DISPLAY_STATE`（ON / DIMMED / OFF）把状态写日志，便于事后判断是"系统调暗"还是"面板层故障"。

## Verification

- 日志出现 `DIMMED` / `OFF` 记录 → 属系统闲置调暗，按上面修；
- 日志无任何记录而屏幕仍暗 → 不是闲置计时器，转查面板/驱动/连线。
- 手柄连续操作 5 分钟以上、全程不碰鼠标键盘，观察屏幕是否还变暗。

## Problem

桌面应用的遥测单测偶红（入队快照断言 3≠2，队列里混进**别处铸的事件**），本机偶绿、门禁必现。异步家族：同一现象还有「状态被写进别人的目录」「活线程把状态写进真实用户配置目录」两个变体。

## Root Cause

后台投递线程里，**文件路径在每次存取时现解析进程级环境变量**：线程 `load_queue()` 时配置目录 env 还指向 A，发送窗口（网络 I/O 达数秒）期间主线程/别的测试把 env 换成 B，`save_queue()` 就把 A 的事件**移植进 B 的文件**。锁、唯一临时目录都没问题——毒源是「一个操作跨越多次 env 现解析」，窗口=操作内的慢环节（发送/重试）。排查线索：队列里多余事件的**铸造时间戳晚于本操作**，且铸造踪显示它来自另一线程。

## Fix

**同一操作内路径定格**：进入操作时解析一次路径，全程用该路径（`*_at(path)` 存取核心 + 各入口定格）；后台线程在 spawn **前**定格路径并带入线程。辅助：测试用临时目录每次唯一；测试收尾把 env 指向**死路**而非删除（防止活线程回落真实用户目录）。

## Verification

原复现组合（两个会并发的用例）连打 **40/40 全绿**（修复前 1-13 轮必红）；全量单测绿；保留仅测试编译的铸造踪（谁在哪铸）供后续竞态排查。

## Problem

Claude Code sessions using MCP tools rapidly consume the 200K context window. A single Playwright snapshot costs 56 KB, twenty GitHub issues cost 59 KB, and one access log costs 45 KB. With 81+ tools active and tool definitions consuming 143K tokens (72%) before the first message, after 30 minutes 40% of context is depleted. This limits productive session time to approximately 30 minutes before significant slowdown occurs.

## Root Cause

MCP tool interactions dump raw data directly into the context window from both directions — tool definitions consume tokens on input, and raw output from tool calls (log files, API responses, snapshots) fills context on output. The raw data generated by tools never gets filtered or compressed before entering the conversation context.

## Solution

Context Mode is an MCP server that intercepts tool outputs through a PreToolUse hook and processes them in an isolated sandbox:

1. Each `execute` call spawns an isolated subprocess with its own process boundary, preventing scripts from accessing each other's memory or state
2. Scripts run in the subprocess and capture stdout; raw data (log files, API responses, snapshots) never leaves the sandbox
3. Only the stdout output enters the conversation context
4. For knowledge bases, the `index` tool chunks markdown content by headings while keeping code blocks intact, storing them in a SQLite FTS5 virtual table
5. Search uses BM25 ranking — a probabilistic relevance algorithm that scores documents based on term frequency, inverse document frequency, and document length normalization
6. Porter stemming is applied at index time so "running", "runs", and "ran" match the same stem
7. The `search` tool returns exact code blocks with their heading hierarchy, not summaries
8. The `fetch_and_index` tool extends this to URLs by fetching, converting HTML to markdown, chunking, and indexing — the raw page never enters context
9. Install via `/plugin marketplace add mksglu/claude-context-mode` or via MCP with `claude mcp add context-mode -- npx -y context-mode`
10. Restart Claude Code

## Notes

Context Mode applies the same compression principle as Cloudflare's Code Mode but targets the output direction of tool interactions. Ten language runtimes are supported: JavaScript, TypeScript, Python, Shell, Ruby, Go, Rust, PHP, Perl, R. Authenticated CLIs (gh, aws, gcloud, kubectl, docker) work through credential passthrough where the subprocess inherits environment variables and config paths without exposing them to the conversation. Bun is auto-detected for 3-5x faster JS/TS execution. Users do not need to change their workflow — the PreToolUse hook automatically routes tool outputs through the sandbox, and subagents learn to use `batch_execute` as their primary tool. Bash subagents get upgraded to general-purpose access to MCP tools.

## Problem

导航页点地图上的抓拍点完全没反应；同一个组件在「识得路」页面工作正常，所以第一反应是数据或坐标问题。

## Root Cause

AMapContainer 的 onSelect 是可选闭包（`var onSelect: ((CapturePoint) -> Void)?`）。认路页传了，导航页漏了。可选闭包不传也能编译，运行时 `onSelect?(...)` 静默什么都不做——没有崩溃、没有警告、没有日志。

## Fix

接入复用组件时把可选回调当必填清单过一遍：

```bash
grep -rn "AMapContainer(" BMSiOS/UI | sed 's/:.*//' | sort -u
```

逐个调用点确认 onSelect / onTapRoute / onLongPress 都传了。更彻底：把回调改成必填 init 参数，或在 init 里断言非 nil（仅 Debug）。

## Verification

两个页面分别点同一个抓拍点都能弹详情；grep 出的每个调用点参数齐全。

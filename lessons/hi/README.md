# हिंदी पाठ (Hindi Lessons)

यह निर्देशिका हिंदी भाषा में प्रोग्रामिंग पाठ प्रदान करती है।

## उपलब्ध पाठ

### मूल बातें (Basics)

1. **हैलो वर्ल्ड** (`basics/hello-world.md`)
   - अपना पहला प्रोग्राम लिखना सीखें
   - कठिनाई: शुरुआती

2. **चर (Variables)** (`basics/variables.md`)
   - चर का उपयोग करके डेटा को स्टोर करना सीखें
   - कठिनाई: शुरुआती

## पाठों का उपयोग कैसे करें

1. शुरुआती लोगों को "हैलो वर्ल्ड" से शुरू करना चाहिए
2. प्रत्येक पाठ में कोड उदाहरण और अभ्यास शामिल हैं
3. अपनी गति से सीखें और प्रत्येक अवधारणा का अभ्यास करें

## योगदान

यदि आप इन पाठों को बेहतर बनाना चाहते हैं या नए पाठ जोड़ना चाहते हैं, तो कृपया योगदान दिशानिर्देशों का पालन करें।

## लाइसेंस

ये पाठ शैक्षिक उद्देश्यों के लिए स्वतंत्र रूप से उपलब्ध हैं।

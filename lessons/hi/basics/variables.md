# चर (Variables)

## परिचय

चर (Variables) प्रोग्रामिंग में डेटा को स्टोर करने के लिए कंटेनर हैं। वे आपको मूल्यों को नाम देने और बाद में उनका उपयोग करने की अनुमति देते हैं।

## उद्देश्य

इस पाठ में आप सीखेंगे:

- चर कैसे घोषित करें
- विभिन्न प्रकार के चर (`let`, `const`, `var`)
- चर नामकरण के नियम
- डेटा प्रकार की मूल बातें

## चर घोषित करना

### `let` का उपयोग

`let` का उपयोग उन चरों के लिए करें जिनका मान बदल सकता है:

```javascript
let नाम = "राज";
let उम्र = 25;

console.log(नाम); // आउटपुट: राज
console.log(उम्र);  // आउटपुट: 25

// मान बदलना
नाम = "प्रिया";
console.log(नाम); // आउटपुट: प्रिया
```

### `const` का उपयोग

`const` का उपयोग उन चरों के लिए करें जिनका मान नहीं बदलना चाहिए:

```javascript
const देश = "भारत";
const PI = 3.14159;

console.log(देश); // आउटपुट: भारत

// यह त्रुटि देगा:
// देश = "नेपाल"; // Error: Assignment to constant variable
```

### `var` का उपयोग (पुराना तरीका)

`var` पुराना तरीका है। आधुनिक कोड में `let` और `const` का उपयोग करें:

```javascript
var शहर = "दिल्ली";
console.log(शहर);
```

## डेटा प्रकार

### 1. संख्या (Number)

```javascript
let संख्या = 42;
let दशमलव = 3.14;
let ऋणात्मक = -10;
```

### 2. स्ट्रिंग (String)

```javascript
let अभिवादन = "नमस्ते";
let नाम = 'राहुल';
let वाक्य = `मेरा नाम ${नाम} है`; // Template literal
```

### 3. बूलियन (Boolean)

```javascript
let सत्य = true;
let असत्य = false;
let क्याबारिशहै = true;
```

### 4. अपरिभाषित (Undefined)

```javascript
let अपरिभाषित;
console.log(अपरिभाषित); // आउटपुट: undefined
```

### 5. नल (Null)

```javascript
let खाली = null;
console.log(खाली); // आउटपुट: null
```

## नामकरण के नियम

### ✅ सही नाम

```javascript
let उपयोगकर्तानाम = "अमित";
let user_age = 30;
let totalAmount = 1000;
let _private = "गुप्त";
```

### ❌ गलत नाम

```javascript
// let 123abc = "गलत";     // संख्या से शुरू नहीं हो सकता
// let my-name = "गलत";    // हाइफ़न की अनुमति नहीं
// let let = "गलत";        // आरक्षित शब्द
```

## व्यावहारिक उदाहरण

### उदाहरण 1: उपयोगकर्ता जानकारी

```javascript
const उपयोगकर्ता = "सीमा";
let आयु = 28;
let शहर = "मुंबई";
const ईमेल = "seema@example.com";

console.log(`नाम: ${उपयोगकर्ता}`);
console.log(`आयु: ${आयु}`);
console.log(`शहर: ${शहर}`);
console.log(`ईमेल: ${ईमेल}`);
```

### उदाहरण 2: गणना

```javascript
let मूल्य = 100;
let कर = 18;
let कुलमूल्य = मूल्य + (मूल्य * कर / 100);

console.log(`मूल मूल्य: ₹${मूल्य}`);
console.log(`कर: ${कर}%`);
console.log(`कुल मूल्य: ₹${कुलमूल्य}`);
```

## अभ्यास

1. अपना नाम, उम्र और पसंदीदा रंग स्टोर करने के लिए चर बनाएं
2. दो संख्याओं को जोड़ें और परिणाम प्रिंट करें
3. एक टेम्पलेट लिटरल का उपयोग करके एक वाक्य बनाएं

```javascript
// आपका कोड यहां लिखें
const मेरानाम = "आपका नाम";
let मेरीउम्र = 0;
const पसंदीदारंग = "नीला";

let संख्या1 = 10;
let संख्या2 = 20;
let योग = संख्या1 + संख्या2;

console.log(`मेरा नाम ${मेरानाम} है और मैं ${मेरीउम्र} साल का हूं।`);
console.log(`${संख्या1} + ${संख्या2} = ${योग}`);
```

## सामान्य गलतियां

### 1. `const` को पुनः असाइन करना

❌ गलत:
```javascript
const नाम = "राज";
नाम = "प्रिया"; // Error!
```

### 2. चर घोषित किए बिना उपयोग करना

❌ गलत:
```javascript
console.log(अघोषित); // Error: अघोषित is not defined
```

✅ सही:
```javascript
let अघोषित = "अब घोषित";
console.log(अघोषित);
```

## सारांश

- `let` का उपयोग परिवर्तनशील मानों के लिए करें
- `const` का उपयोग स्थिर मानों के लिए करें
- चर नाम वर्णनात्मक होने चाहिए
- JavaScript में कई डेटा प्रकार हैं: Number, String, Boolean, आदि

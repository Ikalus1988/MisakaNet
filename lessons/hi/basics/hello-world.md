# हैलो वर्ल्ड

## परिचय

यह पाठ आपको प्रोग्रामिंग की दुनिया में आपका पहला कदम रखने में मदद करेगा। हम एक सरल "हैलो वर्ल्ड" प्रोग्राम बनाएंगे।

## उद्देश्य

इस पाठ के अंत तक, आप सीखेंगे:

- एक बुनियादी प्रोग्राम की संरचना
- कोड को कैसे चलाएं
- आउटपुट को कैसे प्रिंट करें

## कोड उदाहरण

```javascript
console.log("हैलो वर्ल्ड!");
```

## व्याख्या

### `console.log()` क्या है?

`console.log()` एक फ़ंक्शन है जो स्क्रीन पर टेक्स्ट प्रदर्शित करता है। यह डेवलपर्स के लिए सबसे महत्वपूर्ण टूल्स में से एक है।

### कोड कैसे काम करता है

1. **`console`**: यह एक ऑब्जेक्ट है जो ब्राउज़र या Node.js में उपलब्ध है
2. **`.log()`**: यह एक मेथड है जो मैसेज को आउटपुट करता है
3. **`"हैलो वर्ल्ड!"`**: यह स्ट्रिंग है जो प्रदर्शित होगी

## अभ्यास

निम्नलिखित को प्रिंट करने का प्रयास करें:

```javascript
console.log("मेरा नाम [आपका नाम] है");
console.log("मैं प्रोग्रामिंग सीख रहा हूं");
```

## सामान्य गलतियां

### 1. उद्धरण चिह्न भूलना

❌ गलत:
```javascript
console.log(हैलो वर्ल्ड);
```

✅ सही:
```javascript
console.log("हैलो वर्ल्ड");
```

### 2. कोष्ठक बंद न करना

❌ गलत:
```javascript
console.log("हैलो वर्ल्ड";
```

✅ सही:
```javascript
console.log("हैलो वर्ल्ड");
```

## अगले कदम

बधाई हो! आपने अपना पहला प्रोग्राम पूरा कर लिया है। अब आप चर (variables) और डेटा प्रकार (data types) के बारे में सीखने के लिए तैयार हैं।
